# Лес Страха

Одностраничный сайт-макет иммерсивного хоррор-тура по ночному лесу где-то в Сибири.
Статика: только **HTML + CSS**, без JavaScript и сборки.

## Запуск

Открой `index.html` в браузере — или подними любой статический сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Структура

```
index.html        — разметка всех секций (герой, манифест, маршрут, билеты, контакты)
styles/reset.css  — сброс браузерных стилей
styles/fonts.css  — подключение локальных шрифтов
styles/layout.css — структура: сетки, позиционирование, отступы
styles/style.css  — типографика, цвета, эффекты, медиа-запросы
assets/svg/       — векторные иллюстрации (лес, хижина, подземелье, фавикон)
assets/fonts/     — локальные шрифты + лицензии
```

## Особенности

- Макет, а не готовый продукт: кнопки покупки билетов неактивны (`disabled`), навигация — только якоря по странице
- Мобильное меню реализовано на чистом CSS через `:target`
- Шрифты: Cormorant Garamond (заголовки) и Monoid (текст описаний), хранятся локально
- Лицензии шрифтов — в `assets/fonts/OFL-*.txt` (Cormorant, Golos)
